Automated Financial & Stock Report System

MS Excel Pivot Tables Data Analysis VLOOKUP Automated Dashboard

Ringkasan Projek

Perancangan template laporan keuangan dan manajemen stok barang otomatis berbasis Microsoft Excel. Sistem ini dirancang untuk memangkas waktu pengerjaan alur kerja rekapitulasi data bulanan secara signifikan dengan mengombinasikan formula pencarian otomatis, Pivot Table dinamis, dan visualisasi grafik yang interaktif.

Fitur & Keunggulan

  • Automated Data Lookup: Integrasi formula VLOOKUP/XLOOKUP untuk penarikan data transaksi otomatis tanpa input manual berulang.
  • Dynamic Pivot Reporting: Ringkasan arus kas, laba rugi, dan perputaran stok barang yang dapat dipilah berdasarkan periode waktu.
  • Stock Control Alerts: Penanda visual otomatis saat persediaan barang mencapai batas minimum.
  • Executive Summary Dashboard: Tampilan grafik ringkas yang siap dipresentasikan untuk pengambilan keputusan manajemen.
